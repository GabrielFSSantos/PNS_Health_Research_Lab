# ERICA — Prevalence of non-communicable diseases

**PDF versionado:** [../pdfs/erica_prevalence_ncd.pdf](../pdfs/erica_prevalence_ncd.pdf)

## Resumo para o lab

Prevalência de **doenças crônicas não transmissíveis (DCNT)** em bases populacionais brasileiras. Suporta a seleção das 15 comorbidades no agrupamento e a interpretação dos perfis de cluster.

## Uso nas fases

| Fase | Aplicação |
|------|-----------|
| F0, F1 | Conjunto de comorbidades (hipertensão, diabetes, depressão, etc.) |
| F3 | Página Dataset / perfis no dashboard |

## O que tomamos / o que difere

- **Tomamos:** multimorbidade como eixo de segmentação populacional
- **Diferente:** clusters são empíricos (K-Means), não estratos epidemiológicos pré-definidos
