# Prevalências de doenças crônicas na PNS

**PDF versionado:** [../pdfs/prevalencia_dcnt_pns.pdf](../pdfs/prevalencia_dcnt_pns.pdf)

## Resumo para o lab

Estimativas de **prevalência de DCNT** com microdados PNS. Contextualiza a distribuição das comorbidades antes do agrupamento e valida plausibilidade dos perfis.

## Uso nas fases

| Fase | Aplicação |
|------|-----------|
| Parte 0 | Ancoragem epidemiológica |
| F1 | Interpretação dos radares de cluster no dashboard |

## O que tomamos / o que difere

- **Tomamos:** ordem de grandeza e coocorrência de condições crônicas no Brasil
- **Diferente:** não replicamos tabelas de prevalência IBGE no pipeline — usamos snapshot da run (`survey_snapshot.json`)
